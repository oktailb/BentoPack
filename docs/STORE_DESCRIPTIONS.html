5. 🔬 Tutoriel & Protocole de Benchmark Overdraw (YouTube & DevLog) Protocole Reproductible

Ce protocole scientifique démontre rigoureusement à vos utilisateurs et testeurs comment mesurer les gains de performances GPU (réduction d'overdraw de 60 à 80%) sur chaque moteur.

🎮 Protocole de Benchmark Unity

1. Préparation de la Scène de Test

Créez une scène URP 2D avec 1 ou 2 lumières 2D dynamiques (Point Light ou Freeform Light). Dupliquez 300 fois un sprite 2D avec transparence pour simuler une foule d'ennemis ou une végétation dense.

2. Visualisation dans la Vue Scène

Basculez le mode d'affichage en haut à gauche de la Scene View de Shaded à Overdraw.
• Quads classiques : Halo aveuglant blanc et rose fluo (chaque pixel d'écran est recalculé 10 à 15 fois inutilement).
• BentoPack Tight Mesh : Scène vert foncé et bleu calme. Les zones transparentes restent totalement noires !

3. Mesure Chiffrée (Frame Debugger & Profiler)

Ouvrez Window > Analysis > Profiler (module GPU) :
• Temps GPU Quads Classiques : ~16.8 ms (chute à 55 FPS sur mobile/Switch).
• Temps GPU BentoPack Tight Mesh : ~4.9 ms (200+ FPS, soit -70.8% de charge GPU !).

🤖 Protocole de Benchmark Godot 4

1. Scène de Test 2D

Instanciez une grille de 250 nœuds AnimatedSprite2D se chevauchant partiellement avec un PointLight2D.

2. Mode Debug Draw Overdraw

Dans le viewport 2D, cliquez sur le menu de rendu en haut à gauche -> Debug Draw -> cochez Overdraw.
Les quads standards de Godot créent de grands rectangles blancs additifs, tandis que l'ArrayMesh polygonal de BentoPack préserve un fond noir sans gaspillage de fillrate.

3. Métriques

Dans l'inspecteur inférieur Debugger > Monitors, observez le frame time passer de 14.2 ms à 4.1 ms sur GPU intégré !

⚡ Protocole de Benchmark Unreal Engine 5

1. Scène Paper2D

Placez 150 acteurs PaperSpriteActor superposés dans le champ de la caméra avec un éclairage directionnel dynamique.

2. Optimization Viewmodes

Basculez le viewport de Lit à Optimization Viewmodes > Quad Overdraw.
Les PaperSprites standards font virer l'écran au rouge écarlate (sur-ombrage critique). Avec la géométrie BentoPack, la scène repasse en vert/cyan optimal.

3. Profilage Console

Tapez profilegpu ou stat gpu dans la console Unreal. Le coût du pass Translucency chute de 6.8 ms à 1.9 ms (-72% de charge GPU).
